# 🎬 South Indian Movies Analytics Dashboard

## 📌 Overview
This project presents an interactive Power BI dashboard to analyze South Indian movie data and uncover insights through data visualization.

## 🎯 Objectives
- Analyze South Indian movie datasets.
- Visualize trends using interactive dashboards.
- Present key insights through charts and KPIs.

## 🛠️ Tools & Technologies
- Power BI
- Microsoft Excel

## 📊 Dashboard Features
- Language-wise Movie Distribution
- Movie Ratings Analysis
- Genre-wise Analysis
- Interactive Filters & Slicers
- KPI Cards and Visualizations

## 📈 Key Insights
- Identified trends across different South Indian film industries.
- Compared movie ratings, genres, and language distributions.
- Presented insights using interactive Power BI visuals.

## 📂 Project Files
- `south_indian_movies_dashboards.pbix`
- Dataset (Excel)
- Dashboard Screenshot

## 🚀 Outcome
Developed an interactive Power BI dashboard that transforms raw movie data into meaningful insights for better analysis and decision-making.
